Projects

Two projects I built on my own, one in software and one in hardware.

DESQ

A school management system with a built-in learning platform, made for multiple schools on one deployment.

  • Four portals (school admin, teacher, student, and parent), each showing only what that role should see.
  • Gradebook with weighted assessment groups, report cards, transcripts, and PDF export.
  • Courses with lessons, assignments, quizzes that grade themselves, discussions, and a calendar.
  • Real-time notifications and one-to-one messaging over WebSockets.
  • Fee tracking with receipts, public admissions with a waiting list, and custom roles and permissions for each school.
Built with
Laravel, SQL Server, React, TanStack Router and Query, Tailwind CSS
Status
In active development

SmartNest

A connected home prototype that senses its surroundings and opens a door for the right RFID card.

  • Air quality (MQ135), temperature and humidity (DHT11), and ultrasonic sensors for a dustbin.
  • RFID door access (RC522) that recognizes five registered cardholders and swings a servo to open.
  • Several ESP32 and Arduino Uno boards that talk to each other over ESP-NOW and report to the Blynk cloud.
Built with
ESP32, Arduino Uno, ESP-NOW, Blynk, RC522, MQ135, DHT11
Status
Final project, presented as a live demo
